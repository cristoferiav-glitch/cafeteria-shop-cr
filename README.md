# ☕ Cafeteria Shop CR
## 🌐 Acesse o sistema

**Aplicação online:** [Cafeteria Shop CR](https://cafeteria-shop-cr.onrender.com/)

O sistema está hospedado na plataforma Render e pode ser acessado diretamente pelo navegador.
## Sobre o projeto

A Cafeteria Shop CR é uma aplicação web de e-commerce desenvolvida como parte do Projeto Integrador Transdisciplinar II (PIT II), do curso de Sistemas de Informação.

O sistema simula uma cafeteria virtual, permitindo que clientes consultem produtos, adicionem itens ao carrinho, realizem pedidos e acompanhem suas compras.

## Tecnologias utilizadas

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Git e GitHub

## Funcionalidades

- Catálogo de produtos
- Carrinho de compras com controle de quantidades
- Cadastro e autenticação de clientes
- Validação de CPF
- Finalização de pedidos
- Simulação de pagamento via Pix ou cartão
- Histórico de compras do cliente
- Login administrativo
- Aprovação administrativa de pagamentos simulados
- Gerenciamento do status dos pedidos

## Segurança

O projeto utiliza hashes para armazenamento de senhas, consultas SQL parametrizadas e variáveis de ambiente para configurações sensíveis.

Os pagamentos são exclusivamente simulados. Não há integração com uma instituição financeira ou processamento real de cartões.

## Banco de dados

O sistema utiliza MySQL para armazenar informações de produtos, categorias, clientes, pedidos e pagamentos.

## Objetivo acadêmico

Aplicar conhecimentos de desenvolvimento web, programação, banco de dados e engenharia de software na construção de uma solução funcional de comércio eletrônico.
